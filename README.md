# TFA8 - Laravel POS: Resource Controllers and Authentication

This project builds on the provided TFA7 POS application. Customer and user CRUD are now protected by `auth` middleware and use full `Route::resource` routes. Login and registration views, session handling, password hashing, and CSRF protection are included.

## Important authentication note
This ZIP includes a **self-contained Laravel authentication implementation**, not an installation generated by Laravel Breeze. To meet the assignment's **specific Breeze requirement**, install the official Breeze scaffolding in a compatible Laravel environment and reconcile its generated auth files with the custom `users` schema (`username`, `full_name`, `email`, `password`, `avatar`). Do not claim Breeze is installed based on this ZIP alone.

## Setup (PHP 8.2+, Composer, SQLite, Node/npm)

1. `composer install`
2. Copy `.env.example` to `.env` (PowerShell: `Copy-Item .env.example .env`)
3. `php artisan key:generate`
4. `php artisan migrate:fresh --seed` (deletes old local database records)
5. `php artisan storage:link`
6. `php artisan serve`
7. Open `http://127.0.0.1:8000/register`, register an account, then test `/customers` and `/users`.

Avatar processing uses Intervention Image 3 and PHP GD. `npm install` / `npm run build` are optional for the inline-CSS POS pages.

## Tests
Run `php artisan test`. Logged-out visits to `/customers` and `/users` should redirect to `/login`; logged-in users should be able to visit them. Verify customer and user CRUD manually.

## Resource methods
Both controllers implement index, create, store, show, edit, update and destroy.
